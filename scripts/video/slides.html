How it works

One FalkorDB graph; every answer is a set of read-only, parameterized Cypher queries.

In the graph

  • PEPs 745
  • Rejected ideas 1,085
  • Forum threads 1,748
  • Rulings 257
  • CPython PRs 505
  • People 2,175

Edges that carry the evidence

(:Alternative)-[:REJECTED_IN]->(:PEP)
(:PEP)-[:REJECTS_APPROACH_OF {via}]->(:PEP)
(:Alternative)-[:CITES {quote}]->(:PEP)
(:PEP)-[:RESOLVED_BY]->(:Decision)-[:MADE_BY]->(:Person)
(:Thread)-[:DISCUSSES]->(:PEP)
(:Person)-[:EXPERT_IN {rank}]->(:Topic)

  • Web UI and MCP serverthe same tools for people and agents

Can you trust it?

98 questions with known answers. Baseline: vector search over the same data and embedding model.
